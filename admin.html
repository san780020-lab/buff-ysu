首次使用：如何创建令牌
  1. 打开 GitHub Fine-grained token 设置，使用 san780020-lab 登录。
  2. 选择 Only select repositories，仅选择 buff-ysu；设置适当有效期。
  3. Repository permissions：Contents 选 Read and write，Pages 选 Read and write。Metadata 保持默认。
  4. 由你创建并复制令牌，粘贴到上方连接。不要把令牌发到聊天或发布内容里。

这是一次性授权配置；令牌到期或撤销后需要重新创建。入口地址公开，未经身份与写入权限验证无法发布。
